* Pourquoi ViSe n'est pas identifié

Le code remis =etc/nixos/vise-hosting/module.nix= construit son ExecStart avec
=/var/lib/vise/releases/${target.sha256}/server=. Le contrat de l'observateur
n'accepte que les exécutables sous =/nix/store/=. Le dossier d'adoption
prévoyait déjà cette limite avant l'exécution.

C'est une explication cohérente avec les sources, pas une lecture du chemin
réel du processus : plusieurs causes peuvent produire les champs =null=.
Ni =target.json=, ni le binaire, ni les données ViSe n'ont été récupérés par
ce canal. Ne pas inventer d'empreinte ni déplacer le binaire pour obtenir 7/7.
