Les exports originaux sont disponibles dans Git LFS, sans reconstruction ou
modification. Leurs téléchargements complets ont été vérifiés contre les SHA-256
des reçus d'origine. Le déploiement reste à la charge de Spectre.

Forgejo répond 200 sur l'accueil, mais son API de releases répond 403 depuis
Cloud : la disponibilité des archives sur Forgejo n'est pas établie.
L'envoi de pièces jointes GitHub Release a renvoyé 401 ; le brouillon vide créé
pour cet essai a été supprimé. Git LFS a permis la publication des deux fichiers,
dont celui des travailleurs dépasse la limite d'un blob Git ordinaire.

* Contrôle avant utilisation

Vérifier les empreintes externes avant toute extraction dans deux dossiers
distincts, puis toutes les entrées SHA256SUMS de chaque archive. Les archives
contiennent des noms de membres communs : ne pas les fusionner.

Les 14 et 17 membres, les manifestes et les flux Nix décompressés ont également
été revérifiés avant publication. Les preuves d'import d'origine n'ont pas été
réexécutées pour cette simple mise à disposition. Aucune activation n'a été
effectuée depuis Cloud.
