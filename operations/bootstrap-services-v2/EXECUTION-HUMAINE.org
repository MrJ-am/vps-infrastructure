* Portée et revue

L'objectif de déploiement est autorisé. Cette étape fournit les références
nécessaires à l'adoption ; elle ne déploie pas les applications. L'administrateur
utilise son canal existant. Aucun accès root ou shell général n'est transmis à
Cloud ou à un agent Spectre. L'accès SSH d'inventaire n'est pas élargi.

Lire =README.org=, les sources et les preuves de la remise avant le geste.
Le collecteur V2 corrige le confinement insuffisant de V1. L'ancienne remise
est retirée ; ses empreintes restent inchangées. Lire la revue Spectre jointe.
L'entrée C sépare un lecteur sans capacités sous Landlock et un auxiliaire
strictement limité aux liens exe, avec CAP_SYS_PTRACE et seccomp à refus par
défaut. L'unité exclut explicitement les appels de mémoire interprocessus.
Les lectures de fichiers proc mem/environ/cmdline, y compris les alias testés,
sont refusées. Landlock ABI >=3 est obligatoire : aucun repli si indisponible.
Les témoins positifs/négatifs, 24 refus de l'auxiliaire, protections après exec
et limites du protocole sont qualifiés sur des processus synthétiques seulement.
Les fichiers sensibles sont masqués, le réseau IP et les écritures système
refusés. Limites : 120 s, 25 % CPU, 256 Mio, 16 tâches, 64 fd. La revue Spectre
doit vérifier ce périmètre précis, notamment les deux programmes et leurs filtres.

Le rapport contient les six UID/GID fixés, les états de sept unités, leurs
exécutables Nix et métadonnées NAR, ainsi que la génération courante. L'autorité
reste =unverified_observation=. Les métadonnées locales ne prouvent pas le
contenu d'un processus ni une révision source authentifiée.
